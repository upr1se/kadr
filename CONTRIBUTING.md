# Участие в проекте

## Перед отправкой изменений

- Прочитайте `TECHNICAL_SPEC_v2.0.md` и не добавляйте функции вне MVP.
- Сохраняйте офлайн-модель, минимум разрешений и отключённый Android Backup.
- Не добавляйте `INTERNET`, широкий доступ к хранилищу, аналитику или сетевые
  SDK.
- Не отправляйте keystore, пароли, APK, персональные данные и реальные книги.
- Тестовые FB2 должны быть синтетическими или находиться в общественном
  достоянии.

## Проверка

Перед Pull Request выполните:

```powershell
.\gradlew.bat testDebugUnitTest
.\gradlew.bat lintDebug
.\gradlew.bat assembleDebug
```

Изменения пользовательского интерфейса дополнительно проверяются через
`connectedDebugAndroidTest`.

## Безопасность

Не открывайте публичный Issue с работоспособным эксплойтом. Используйте
порядок из [SECURITY.md](SECURITY.md).
