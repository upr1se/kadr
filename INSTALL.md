# Установка и проверка APK

## Требования

- Android 8.0 или новее.
- Разрешение установки приложений из источника, из которого вы скачали APK.
- Официальный package: `com.upr1se.kadr`.

Репозиторий не содержит DRM-средств и книг. Импортируйте только файлы, которые
вы вправе использовать.

## Контрольная сумма

Скачайте APK и соответствующий файл `.sha256` со страницы
[Releases](https://github.com/upr1se/kadr/releases/latest).

Windows PowerShell:

```powershell
Get-FileHash .\kadr-1.0.0-release.apk -Algorithm SHA256
```

Linux или macOS:

```bash
sha256sum kadr-1.0.0-release.apk
```

Полученное значение должно совпасть с файлом `.sha256`.

## Подпись

Официальные release APK подписаны сертификатом со SHA-256:

```text
20f4b798fc74c280399a39024c007ba6b933e7e1e98ac2c8a60a94ab8fbc2125
```

Проверить подпись можно Android Build Tools:

```bash
apksigner verify --verbose --print-certs kadr-1.0.0-release.apk
```

## Установка

1. Откройте скачанный APK.
2. Разрешите установку из выбранного источника.
3. Подтвердите установку.
4. Запустите `кАдр` и добавьте книгу FB2 или FB2.ZIP.

## Обновления

Все будущие версии должны быть подписаны тем же сертификатом. Обычный APK
обновляется поверх предыдущего release без удаления библиотеки.

Debug-сборка имеет другую подпись. Перед установкой release APK поверх debug
её нужно удалить; данные тестовой установки при этом будут потеряны.
