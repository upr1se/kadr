# Безопасность

## Поддерживаемые версии

Исправления безопасности выпускаются для актуального релиза ветки `1.0.x`.

## Как сообщить об уязвимости

Не публикуйте рабочий эксплойт, текст книги, персональные данные или полные
внутренние пути в обычном Issue.

Используйте приватный GitHub Security Advisory:

https://github.com/upr1se/kadr/security/advisories/new

Опишите версию APK, модель устройства и версию Android, минимальные шаги
воспроизведения и ожидаемое безопасное поведение. Приложите синтетический
минимальный FB2, если проблема связана с импортом или разбором.

## Проверка релиза

Официальные APK:

- подписаны ключом `kadr`;
- имеют `applicationId` `com.upr1se.kadr`;
- собраны с отключёнными `debuggable` и Android Backup;
- не запрашивают `INTERNET`;
- публикуются вместе с SHA-256.

Ожидаемый отпечаток сертификата SHA-256:

```text
20f4b798fc74c280399a39024c007ba6b933e7e1e98ac2c8a60a94ab8fbc2125
```

Порядок проверки описан в [INSTALL.md](INSTALL.md).
